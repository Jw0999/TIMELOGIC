# Problem & Solution

## ❌ The problem
Traditional attendance (paper sheets, fingerprint clocks, basic apps) is **easy to game**:

| Cheat | How it happens |
|---|---|
| Remote clock-in | Marking attendance from home or anywhere off-site |
| Buddy punching | A coworker clocks you in while you're absent |
| Phone sharing | One device used to check in several people |
| Replay / scripts | Reusing an old QR/code or automating check-in |
| Break abuse | Long breaks, or "returning" without actually coming back |
| Forgotten sessions | Admin forgets to open the day → no records |
| Lost data | Records edited or deleted, no audit trail |

The result: **inflated hours, payroll leakage, and no trust in the numbers.**

## ✅ The solution — TimeLogic
A check-in only counts when it passes **three independent layers** (see [[The 3-Layer Verification]]):

> [!success] All three must pass, or it does not count
> 1. **Network** — you're on the company Wi-Fi / office network.
> 2. **Device** — it's your one registered phone.
> 3. **Time** — a short-lived one-time code, inside the allowed window.

Plus the system **runs itself**: sessions auto-open and auto-close, late/penalty rules apply automatically, breaks are tracked with return checks, and a **live fraud engine** flags anything suspicious. Nothing is ever deleted.

## 🎯 The outcome
- Attendance numbers you can put on payroll without second-guessing.
- Zero manual upkeep for the common cases.
- A full, permanent audit trail, exportable to Excel/CSV.
