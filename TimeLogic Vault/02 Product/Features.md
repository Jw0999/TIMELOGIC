# Features

## 🔐 Verification & security (the core)
- **Wi-Fi verified check-in** — counts only on the company network. Off Wi-Fi / on mobile data → no check-in. (Android = Wi-Fi SSID; iPhone/web = office public IP.) → [[The 3-Layer Verification]]
- **One device per employee** — each account locks to one phone on first use; other/borrowed phones rejected. Buddy-punching impossible.
- **Time-based check-in codes** — short-lived one-time code; old codes, screenshots, and scripts never work.
- **Screenshot protection** — employee app blocks screenshots / screen recording to protect codes & data.

## ⏱️ Attendance automation
- **Automatic sessions** — open on schedule from the set opening time; if an admin forgets, the backend opens one automatically.
- **Smart late & penalty rules** — per-org open/close times, grace periods, late thresholds, penalties — measured from the official opening time.
- **Auto check-out** — at closing time, anyone still clocked in is checked out automatically, so hours stay accurate.

## ☕ Breaks & 🌴 leave
- **Honest break tracking** — breaks set per department; Wi-Fi presence confirms returns and flags overstays / off-network returns.
- **Leave management** — employees request with a reason; admins approve/reject; per-type balances tracked automatically.

## 🚨 Oversight
- **Live fraud alerts** — real-time flags: off-network breaks, overstays, repeated failed check-ins, device mismatches. → [[Anti-Cheat & Fraud]]
- **Reports & exports** — full attendance, break, leave, and session history as Excel or CSV. **Nothing is ever deleted.**

## 🏢 Platform
- **Built to scale** — hundreds of organizations, thousands of employees, fully isolated, each with its own hours, departments, and Wi-Fi.
- **Multi-surface** — Android, iPhone/web PWA, Desktop admin, Super-Admin web. → [[Platforms & Download Links]]
- **Light & dark theme** — the employee app matches the Android app and follows the phone's light/dark/system setting.
